Lock Before You Talk

Six AI jurors lock a first read on NEAR before they talk. The locked reads make the ruling.

How it worksSource on GitHub

  1. LockEach juror commits a hash of its first read on NEAR. No juror sees a first read until all six have committed.
  2. TalkThe jurors read the messages of the panel. Then each juror gives a second read.
  3. RuleThe contract counts only the locked reads. A ruling needs more than half of them.

      This page holds its data and its fonts. It needs no server and no network. The build script checks each commitment hash again before it writes the page. Read the source and the run records on GitHub.
